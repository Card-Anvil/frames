# attic

Frame art that no package references.

These files were carried over from Card Anvil's `src/templates/` so nothing was
lost in the split, but nothing imports them and they are not part of any frame.
They are kept here — outside `packages/` — so it is obvious they ship with no
code, rather than sitting inside a frame package looking intentional.

- `universesBeyond/` — a Universes Beyond frame family that was never wired up.
  The UB crown art that _is_ live lives in `frame-borderless` under
  `regular/crowns/ub/`, not here.
